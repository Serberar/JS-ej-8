# Ejercicios de JavaScript · 8. Asincronía

Ejercicios sobre código asíncrono en JavaScript: callbacks, peticiones HTTP con `fetch` y `async/await`. Cada ejercicio tiene su enunciado (`.md`), la solución (`.js`) y, en la mayoría, una página `.html` para probarlo en el navegador.

## Contenido

| Carpeta | Tema |
|---|---|
| `1.callbacks` | Pasar funciones como parámetro (por ejemplo, una calculadora con `sum` y `subtract`). |
| `2.fetch` | Consultar la API de Agify con el nombre escrito en un input y pintar cada resultado como un párrafo que se puede borrar. |
| `3.async-await` | Pasar promesas y `fetch` (API de Rick and Morty) a `async/await`. |

## Cómo verlos

Abre el `.html` de cada ejercicio en el navegador (con la consola abierta), o ejecuta en Node los que no tienen página:

```bash
node 3.async-await/exercise-1.js
```
